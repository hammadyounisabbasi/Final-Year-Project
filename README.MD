# Autonomous Campus Operating System (ACOS)

## Overview

The Autonomous Campus Operating System (ACOS) is a research-based Final Year Project that transforms traditional Campus Management Systems into an intelligent, secure, and autonomous ecosystem using Multi-Agent Artificial Intelligence and Zero-Trust Architecture.

## Objectives

- Automate academic and administrative workflows
- Implement AI-powered autonomous agents
- Ensure transparency and accountability
- Secure the system using Zero-Trust principles
- Provide intelligent decision support

## Technology Stack

- Python
- FastAPI
- LangGraph
- Ollama
- SQLite
- FAISS
- HTML
- CSS
- JavaScript
